# Autotrophe
A simple system wide autocorrect for windows

# Installation
Unzip the folder and run the .exe file. 

# Usage
The autocorrect should work immediately. Check your system tray to make sure the program is running. Right click on the tray icon to open the settings menu, and turn on the run after startup feature.

# Notes
DO NOT move the folder after the run after startup feature is turned on. If you do, the feature may break. Uncheck and recheck the box if it does.
